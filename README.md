# AQI-Prediction-Kolkata
Machine Learning Based AQI Prediction System using Kolkata WBPCB (2024-25) air quality data and Random Forest Regression

## Project Overview:
This project focuses on predicting the Air Quality Index (AQI) for different locations in Kolkata using Machine Learning techniques. The dataset contains pollutant concentrations such as PM2.5, PM10, NO2, SO2, CO, NH3, Ozone, and meteorological parameters collected from multiple monitoring stations across Kolkata.

The project includes:
- Data cleaning and preprocessing
- AQI calculation using CPCB pollutant sub-indices
- Exploratory Data Analysis (EDA) using heatmaps, boxplots, and correlation analysis
- Feature selection and handling missing values
- AQI prediction using Random Forest Regressor
- Model evaluation using R² Score and Mean Absolute Error (MAE)

The trained model achieved:
-R2 Score: 0.9963898342091808
-MAE: 0.8848581672042999

This project demonstrates the use of machine learning for environmental monitoring and air quality analysis.
